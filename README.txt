Markov Toys — форма заказа из листа ожидания

Откройте index.html в браузере. Для размещения на сайте загрузите весь каталог
markovtoys-order целиком, сохранив папку assets рядом с index.html.

Форма работает без сервера: данные остаются в браузере, пока клиент не скопирует
сообщение и сам не отправит его в чат. Платежи и заказы автоматически не создаются.

Границы веса: 1–1900 г — 6300 ₽; 1901–2500 — 6800 ₽; 2501–3000 — 7250 ₽;
3001–3500 — 7500 ₽; 3501–3800 — 8300 ₽; 3801–4200 — 9000 ₽;
4201–5500 — 9500 ₽. При весе больше 5500 г нужна индивидуальная цена.

Файлы palette-1.jpeg, palette-2.jpeg, palette-3.jpeg и price-list.jpeg —
исходные изображения. Карточки fabric-01.png…fabric-12.png вырезаны из них
без цветокоррекции.
